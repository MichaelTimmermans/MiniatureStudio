How does this work?
  • Photo takes one full-resolution picture (P key). It is saved in the background — you can keep shooting.
  • Focus stack: several photos of the same model, each focused a bit deeper, merged into one sharp image. Manual: press Start stack, set focus, press + Frame (Space) per depth, then Finish. Lens sweep (autofocus cameras): set start and end, the camera does the rest.
  • Stack processing decides when stacks are merged: When idle waits until you have not shot anything for a few minutes, so the Pi stays fast while you work; Immediately starts right after Finish; Manually waits for Process in the Stacks tab.
  • Tips: Focus check (next to the preview) shows a 100 % crop and a sharpness number — click the preview to choose the spot. The header shows whether anything runs in the background (✓ idle / ⚙ busy) and how loaded the Pi is.

        Storage
        
–

        

        

          
          
          
          
        

        
Photos, stacks and videos go to a MiniatureStudio folder on the disk.
          ext4, exFAT, FAT32 and NTFS work; the disk is mounted again at every boot and when you replug it.
          A USB SSD is fastest and wears least.
